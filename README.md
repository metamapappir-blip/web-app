### نسخه ترکیبی خفن v2.0 چطور اجرا کنم؟

**روش 1 - اجرای مستقیم (بدون EXE):**
```bash
pip install PyQt5 PyQtWebEngine
python aniner-browser/src/aniner_v2.py
```

**روش 2 - ساخت EXE واقعی ویندوز (روی ویندوز):**
```bash
# روی ویندوز:
BUILD_WINDOWS.bat
# یا دستی:
pip install PyQt5 PyQtWebEngine pyinstaller
pyinstaller --onefile --windowed --icon=assets/icon.ico --name Aniner-v2-Real src/aniner_v2.py
# فایل dist/Aniner-v2-Real.exe ساخته شد!
```

**روش 3 - نسخه سبک C (همین EXE 838KB):**
```bash
# از قبل ساخته شده - فقط دانلود و اجرا!
Aniner.exe + WebView2Loader.dll
```
