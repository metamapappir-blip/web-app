# پی‌سی‌اسکوپ (PCScope)

**یک تست‌کننده سبک سخت‌افزار برای ویندوز.** یک فایل exe، بدون نصب، بدون جمع‌آوری
اطلاعات و بدون نیاز به حساب کاربری. تست‌ها را انتخاب کنید، دکمه اجرا را بزنید و
در پایان گزارش را به صورت HTML، متنی یا JSON ذخیره کنید.

## دانلود

فایل **`PCScope.exe`** را از
[آخرین نسخه منتشرشده](https://github.com/metamapappir-blip/web-app/releases/tag/pcscope-v1.0.0)
بگیرید. هیچ چیز نصب نمی‌شود و تنها فایلی که برنامه خارج از پوشه خودش می‌سازد،
گزارشی است که خودتان ذخیره می‌کنید.

**لینک مستقیم دانلود:** <https://github.com/metamapappir-blip/web-app/releases/download/pcscope-v1.0.0/PCScope.exe>

اگر ترجیح می‌دهید با PowerShell انجام شود (دانلود، بررسی چک‌سام و اجرا):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Download-PCScope.ps1 -AsAdministrator
```

اسکریپت `Download-PCScope.ps1` (و فایل `Download-PCScope.bat` برای اجرا با دو کلیک)
فایل اجرایی را از Release می‌گیرد، چک‌سام SHA-256 آن را با `SHA256SUMS.txt` مقایسه
می‌کند، قفل «دانلود از اینترنت» را برمی‌دارد و برنامه را اجرا می‌کند. با
`-DownloadOnly` فقط دانلود انجام می‌شود و با `-Destination C:\Tools` می‌توانید
پوشه دیگری را انتخاب کنید.

ویندوز برای فایل‌های اجرایی امضا‌نشده هشدار می‌دهد: روی
**More info ← Run anyway** بزنید. برای اطمینان می‌توانید چک‌سام فایل را با
`SHA256SUMS.txt` مقایسه کنید:

```bat
certutil -hashfile PCScope.exe SHA256
```

> **نکته:** برای دیدن دما و دور فن، برنامه را با گزینه **Run as administrator**
> اجرا کنید؛ در بیشتر لپ‌تاپ‌ها این سنسورها فقط برای برنامه‌های با دسترسی مدیر
> در دسترس است.

## طرز استفاده

۱. تست‌های مورد نظر را تیک بزنید (به‌طور پیش‌فرض همه تست‌های غیرتعاملی فعال‌اند).
۲. در پایین سمت چپ، حجم فایل تست دیسک و مدت تست استرس را انتخاب کنید.
۳. **اجرای موارد انتخاب‌شده** را بزنید. هر زمان خواستید با **توقف** متوقف کنید.
۴. **ذخیره گزارش (HTML)** را بزنید؛ یا با **کپی خلاصه** یک متن کوتاه برای
   ارسال در چت یا تیکت بسازید.

با دکمه **فارسی / English** بالا سمت چپ، زبان رابط عوض می‌شود.

### خط فرمان

فایل `PCScopeCLI.exe` همان تست‌ها را بدون پنجره اجرا می‌کند؛ مناسب اسکریپت،
پشتیبانی از راه دور یا یک بررسی سریع در PowerShell:

```bat
PCScopeCLI.exe --all --out-dir "%USERPROFILE%\Desktop\PCScope reports"
PCScopeCLI.exe --quick --only cpu,memory,disk --lang fa --html report.html
PCScopeCLI.exe --list            :: نمایش شناسه تست‌ها
PCScopeCLI.exe --all --json out.json
```

گزینه‌های کاربردی: `--all`، `--only`، `--skip`، `--quick`، `--lang en|fa`،
`--txt`، `--html`، `--json`، `--out-dir`، `--disk-mb`، `--memory-mb`،
`--stress-minutes`، `--quiet`. اگر تستی مشکل گزارش کند، کد خروج برنامه `1`
خواهد بود.

اجرا از روی کد منبع:

```bat
python main.py                 :: رابط گرافیکی
python main.py --cli --all     :: اجرا بدون رابط
```

## چند نکته درباره اعداد

- **خودتان را با خودتان مقایسه کنید، نه با اینترنت.** امتیازها به پروفایل برق،
  بار برنامه‌های دیگر، خنک‌کنندگی و درایورها وابسته است. یک بار وقتی دستگاه
  سالم است گزارش بگیرید و بعداً همان را دوباره اجرا و مقایسه کنید.
- **قبل از تست دیسک، حافظه و استرس برنامه‌های دیگر را ببندید**؛ این تست‌ها حجم
  زیادی داده جابه‌جا می‌کنند.
- **سرعت خواندن دیسک در فایل‌های کوچک ممکن است غیرواقعی بالا باشد**، چون ویندوز
  داده‌ها را در رم کش می‌کند. برای عدد قابل اتکا، اندازه ۱ یا ۲ گیگابایت را
  انتخاب کنید.
- **تست سرعت از endpoint عمومی کلودفلر** (`speed.cloudflare.com`) استفاده می‌کند
  و برای تاخیر به `1.1.1.1` و `8.8.8.8` پینگ می‌زند. هیچ اطلاعاتی از دستگاه شما
  ارسال نمی‌شود؛ در تست آپلود فقط ۱ مگابایت داده تصادفی فرستاده می‌شود که دور
  انداخته می‌شود.
- **نمایش «هیچ سنسوری گزارش نشد»** برای دما در بسیاری از کامپیوترهای رومیزی و
  لپ‌تاپ‌هایی که درایور کارخانه را ندارند طبیعی است و به معنی خرابی نیست.

## ساخت از کد منبع

به پایتون ۳.۱۰ تا ۳.۱۳ (۶۴ بیت) نیاز دارید.

```bat
pip install -r requirements-build.txt
pyinstaller --noconfirm --clean pcscope.spec
```

یا فقط **`build.bat`** را اجرا کنید. خروجی در پوشه `dist` قرار می‌گیرد:

- `PCScope.exe` - برنامه گرافیکی
- `PCScopeCLI.exe` - نسخه خط فرمان

وابستگی‌ها عمداً کم هستند: `psutil` برای دسترسی به سخت‌افزار و
`arabic-reshaper` + `python-bidi` برای نمایش درست متن فارسی در Tkinter.

### تست‌ها

```bat
python tests/test_smoke.py
```

همه تست‌ها را بدون رابط اجرا می‌کند؛ حتی رابط گرافیکی هم با یک `tkinter`
شبیه‌سازی‌شده بررسی می‌شود تا روی سرورهای CI که صفحه‌نمایش ندارند هم کار کند.
بیلد ویندوز توسط
[`.github/workflows/pcscope-build.yml`](../../.github/workflows/pcscope-build.yml)
ساخته می‌شود که همین تست‌ها را قبل از بسته‌بندی اجرا می‌کند.
