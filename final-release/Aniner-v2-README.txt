📦 فایل‌ها:

- Aniner-Tabs.exe (770KB) - نسخه با تب
- Aniner-Setup.exe (834KB) - نصاب با آیکون دسکتاپ

- WebView2Loader.dll - موتور Edge

🚀 نصب:
1. برای نسخه سبک: Aniner.exe + WebView2Loader.dll رو کنار هم بذار و اجرا کن
2. برای نسخه ترکیبی خفن:
   - BUILD_WINDOWS.bat رو اجرا کن (روی ویندوز)
   - یا: pip install PyQt5 PyQtWebEngine && python src/aniner_v2.py

🖥️ آیکون دسکتاپ:
- Aniner-Setup.exe رو اجرا کن - خودکار میسازه
- یا Create-Desktop-Shortcut.bat
