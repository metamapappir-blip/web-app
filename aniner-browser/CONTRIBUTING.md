# 🤝 مشارکت در Aniner Browser

## چطور کمک کنی ستاره زیاد بگیریم؟

### 1. ⭐ ستاره بده!
مهم‌ترین کار! روی دکمه Star کلیک کن.

### 2. 🐛 باگ گزارش کن
Issue جدید باز کن، باگ رو توضیح بده.

### 3. 💡 قابلیت پیشنهاد بده
چه قابلیتی دوست داری؟ Issue باز کن!

### 4. 🔧 کد بزن
```bash
git clone https://github.com/metamapappir-blip/web-app.git
cd web-app/aniner-browser
# کد بزن
git checkout -b feature/amazing-feature
git commit -m "Add amazing feature"
git push origin feature/amazing-feature
# Pull Request بده
```

### 5. 📢 معرفی کن
- توییتر، تلگرام، اینستا
- ردیت، HackerNews، ProductHunt
- یوتیوب، آپارات

## ساختار کد

- `src/aniner.c` - نسخه C سبک (838KB EXE)
- `src/installer.c` - نصاب با آیکون دسکتاپ
- `src/aniner_pyqt.py` - نسخه PyQt پیشرفته
- `main.js` - نسخه Electron
- `renderer/` - UI
