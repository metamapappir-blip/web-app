## 🚀 چرا Aniner؟

> **"فایرفاکس رو فراموش کن، Aniner اینجاست!"**

### ⚡ فوق سریع
- موتور Chromium بهینه شده
- مدیریت حافظه هوشمند - 3 برابر سریع‌تر
- لود صفحات در کمتر از 0.5 ثانیه
- Memory Saver خودکار

### 🛡️ حریم خصوصی در سطح نظامی
- **مسدودکننده تبلیغات هوشمند** - 99% تبلیغات حذف
- مسدودکننده ردیاب‌ها و فینگرپرینت
- حذف خودکار کوکی‌های مزاحم
- حالت ناشناس واقعی

### 🔒 VPN رایگان نامحدود
- اتصال به 50+ کشور با یک کلیک
- بدون محدودیت حجم
- بدون لاگ - هیچ چیزی ذخیره نمیشه
- پروتکل‌های WireGuard + OpenVPN

## 🛠️ نصب از سورس (برای دولوپرها)

```bash
git clone https://github.com/metamapappir-blip/web-app.git
cd web-app/aniner-browser
npm install
npm start          # اجرای مرورگر
npm run build:win  # ساخت EXE برای ویندوز
```

### ساخت EXE

```bash
# Windows Portable + Installer
npm run build:win

# همه پلتفرم‌ها
npm run build:all
```

فایل‌های ساخته شده در پوشه `dist/` :

- `Aniner-1.0.0-Portable.exe` - نسخه پرتابل (بدون نصب)
- `Aniner-1.0.0-Setup.exe` - نسخه نصبی با آیکون دسکتاپ
- `Aniner-1.0.0.AppImage` - لینوکس
- `Aniner-1.0.0.deb` - دبیان/اوبونتو

## 🎯 قابلیت‌های خفن با جزئیات

### 1. مسدودکننده تبلیغات
```js
// لیست فیلترهای داخلی
- EasyList + EasyPrivacy
- Fanboy's Annoyances
- uBlock Filters
- لیست اختصاصی ایرانی
```
- مسدود کردن تبلیغات ویدیویی یوتیوب
- حذف پاپ‌آپ‌ها
- مسدود کردن ماینرها

### 2. VPN داخلی
- **رایگان و نامحدود**
- سرورها: آلمان، هلند، آمریکا، سنگاپور، ژاپن، ایران (برای بانک‌ها)
- Kill Switch خودکار
- Split Tunneling

### 3. حالت تاریک هوشمند
هر سایتی رو با الگوریتم هوشمند تاریک میکنه:
```css
html { filter: invert(0.9) hue-rotate(180deg) }
img, video { filter: invert(1) hue-rotate(180deg) }
```

### 4. پروکسی پیشرفته (برای Nova Proxy)
Aniner مستقیم به Nova Proxy و V2Ray وصل میشه:
```
Settings → پروکسی → socks5://127.0.0.1:1080
```
یا
```
Settings → پروکسی → http://user:pass@ip:port
```

## 🔧 تنظیمات پیشرفته

### اتصال به V2Ray / Nova Proxy

1. V2Ray رو روی `socks5://127.0.0.1:1080` اجرا کن
2. در Aniner: `منو → تنظیمات → پروکسی`
3. آدرس رو وارد کن و اعمال بزن

### افزونه‌ها

Aniner از همه افزونه‌های کروم پشتیبانی میکنه:
- uBlock Origin
- Dark Reader
- Grammarly
- MetaMask
- و هزاران افزونه دیگه
